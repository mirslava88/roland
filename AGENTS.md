# Правила проекта

## Версии macOS

- По прямому указанию владельца от 19 октября 2026 года версия Mac-приложения закреплена на **1.1.6** для Standard и **1.1.6-stream** для Stream.
- Не повышать и не менять номер версии при исправлениях, сборках и подготовке релизов, пока владелец прямо не попросит изменить его. Источник версии Mac: `build/mac-runtime.json`.
- Повторные выпуски той же версии различаются только технической ревизией `releaseRevision` и Git-тегом (`macos-v1.1.6-build.<ревизия>`, для Stream — с окончанием `-stream`). Версия приложения, настройки и имена DMG остаются 1.1.6 / 1.1.6-stream.
- Уже опубликованные выпуски 1.1.7 и 1.1.8 являются историей публикаций. Не переименовывать их и не подменять существующие теги или установщики автоматически из-за закрепления версии.
- Изменения Windows не входят в текущую задачу; не менять Windows-версии и Windows-специфичный код без отдельного запроса.
