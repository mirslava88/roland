# PDM: устранение гонок, 23 сентября 2026

Локальные изменения поверх существующей рабочей копии 1.1.6; без коммита,
публикации релиза и изменения версии. Не является доказательством отсутствия
всех возможных гонок в приложении.

## Исправления

| Область | Защита |
| --- | --- |
| Восстановление PowerPoint | Целевой экран и его геометрия повторно определяются **после входа** в очередь Office. Устаревшие metrics-задачи пропускаются; автоматическое восстановление не переносит PPTX на основной экран оператора. |
| Фоновая синхронизация Сцены и внутреннего выхода | Использует ту же очередь, что переключение канала. Отменённая работа проверяется после ожиданий; ошибка относится к своей, а не к новой ревизии Сцены. |
| Публикация Сцены | Новая публикация и выход из эфира отменяют старую. Публикуется сохранённый на момент нажатия черновик. Закрытие **редактора** не отменяет начатую публикацию: её жизненный цикл отделён от окна настроек. |
| Навигация PPTX | Ответ старой цепочки goto не меняет новый слайд, не забирает новый pending target и не освобождает чужое ожидание завершения. |
| Виртуальная камера | Start резервирует поколение до проверки регистрации; Stop отменяет ожидающий Start. Ошибка старого запуска не останавливает новый процесс. |
| Возврат виртуальной камеры на монитор | Команда и нативное подтверждение содержат requestId. Проверяются текущий запрос и наличие дисплея; при отсутствии подтверждения возвращается внутренний захват. Нативный host пересобран. |
| Стрим | Асинхронный захват и ошибки привязаны к своему encoder/epoch. Поздний кадр или отказ старого capturePage не записываются в новый стрим и не останавливают его. |
| Stream Deck | Подключение резервируется до первого await; конфигурация/отключение отменяют старые попытки. Ошибка отрисовки или яркости прежнего устройства не закрывает новое. |
| Панель задач | Изменение топологии инвалидирует и ещё не завершённое скрытие. Работа с Explorer переведена на ShowWindowAsync с ограниченным ожиданием подтверждения, без блокирующего ShowWindow для панели задач. |
| Библиотека файлов | Позднее чтение предыдущей папки не заменяет список текущей. Навигация, первоначальная загрузка и обновление используют ревизию запроса. |
| Сохранение QR-секрета | Запись и удаление сериализованы; поздняя запись не восстанавливает удалённое значение. Чтение ждёт завершения очереди. |

## Воспроизводимые проверки

- `node scripts/test-race-regressions.cjs`: 17 управляемых конкурентных сценариев,
  фактические TypeScript-методы с подменёнными устройствами и задержанными promise.
  Проверяет безопасный результат, а не наличие текста в исходниках. Включён в
  `test:critical`.
- `node scripts/test-critical.mjs all`: 22 группы, включая Standard/Stream builds,
  нативную камеру, PowerShell/C#, обучение, интерфейс, QR/таймер, видеослои,
  кэш и восстановление PPTX, локальные FFmpeg/RTMP проверки. Первый полный прогон
  прошёл 22/22. Повторный прогон на финальном коде выявил нестабильное ожидание
  отрисовки в UI-тесте углов PPTX; тест дополнен `image.decode()` и ограниченным
  ожиданием фактических пикселей скрытого окна. Последний отдельный полный
  `test-program-scene-video-ui.mjs` прошёл, включая углы, QR, таймер, слои и GPU
  chroma key. Не заявляется повторный цельный 22/22 прогон после правок теста.
- Живые проверки на подключённом внешнем экране: переключение PPTX/PDF,
  реальный Office, Сцена, USB-камера и работающий native host виртуальной камеры.
  После исправления закрытия редактора проверен правильный размер PPTX в Сцене.
- Без назначенного Program-монитора: по четыре реальных переключения PPTX/PDF в
  обычном эфире и Сцене, виртуальная камера остаётся на внутреннем захвате.
  Назначения экранов автоматически восстанавливаются после теста.
- Итоговый `test-runtime-smoke.mjs`: операторский интерфейс отрисован,
  Program-дисплей назначен, Stream Deck подключён. Тестовый эфир и камера
  остановлены; PDM оставлен запущенным. `git diff --check` прошёл.

Снимки и промежуточные результаты находятся в `tmp/race-fixes-live-*` и не
предназначены для публикации. Тест различает физический захват (native HWND
PowerPoint входит в итоговый кадр) и Chromium-захват: прозрачная служебная
подложка не считается изображением, доставленным виртуальной камерой.

## Ограничения проверки

- Физическое выдёргивание HDMI/USB не автоматизировалось. Последовательности
  remove/add и запоздавших ACK проверены детерминированными тестами; отключение
  назначения Program проверено в реальном приложении, но не заменяет тест
  конкретного драйвера при физическом отключении кабеля.
- Не выполнялась проверка удалённого клиента ВКС или отправка на внешний
  стриминговый сервис. Интеграционные сетевые тесты используют локальные приёмники.
- Строгий `tsc --noEmit` не проходит: в рабочем проекте остаются ошибки типов
  (включая nullable channel.file в PreviewPanel, типы Electron NativeImage,
  data-атрибуты и несколько других модулей). Успешная сборка Vite не равна
  успешной строгой проверке TypeScript.
- В UI-тесте синтетические PointerEvent дают диагностические NotFoundError
  при setPointerCapture; утверждения перетаскивания проверяются отдельно.

Не обещаем «гонок больше нигде нет»: эти тесты фиксируют найденные сценарии,
а аппаратные сбои и длительную нагрузку нужно проверять отдельными прогонами.
