# Установка виртуальной камеры вместе с PDM — 24 сентября 2026

## Причина

Предыдущий установщик запускал регистрацию системного источника, но не останавливался, если команда завершалась ошибкой. При обновлении он удалял прежнюю регистрацию и пытался перезаписать ту же DLL в `ProgramData`. Если DLL ещё использовалась Windows или приложением видеосвязи, `CopyFileW` возвращал код 32 (`ERROR_SHARING_VIOLATION`). PDM устанавливался без камеры; повторная установка через настройки упиралась в тот же занятый файл.

## Исправление

- Источник копируется в защищённый системный каталог под именем с SHA-256 его содержимого. Новая версия не перезаписывает загруженную старую DLL; одинаковая версия повторно использует уже размещённый файл.
- Установщик регистрирует компонент и отдельно проверяет регистрацию. При ошибке выводит код и прекращает установку вместо ложного успеха. Обычная установка PDM включает камеру без отдельного действия в настройках. Кнопка в настройках оставлена только для восстановления повреждённой регистрации.
- Standard и Stream отмечают владение общим системным компонентом. Удаление одной обновлённой редакции не снимает регистрацию, пока установлена другая.
- Если старая DLL занята при удалении, Windows может временно оставить её в `ProgramData`; активная регистрация указывает на новый файл. Старые незадействованные копии можно очищать отдельной безопасной процедурой после освобождения Windows, но установщик не удаляет загруженную DLL принудительно.

## Проверка

- Нативный regression test удерживает старую DLL без права записи/удаления и проверяет повторное размещение той же версии, переход на другую версию и сохранность занятой старой DLL.
- TypeScript и тест виртуальной камеры прошли. Оба NSIS-установщика собраны с проверкой ресурсов и Electron fuses.
- На тестовой Windows 11 обе редакции установлены из новых локальных установщиков. Каждый установщик завершился кодом 0; после обоих запусков системная регистрация присутствует, оба владельца отмечены, а DirectShow перечисляет `PDM Virtual Camera`.

Исправление подготовлено для обновления существующих релизов 1.1.6 Standard и Stream без смены номера версии.
