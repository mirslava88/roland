# Presentation Display Manager 1.1.7

Windows x64, обычная редакция без встроенного стриминга. [Stream-редакция](https://github.com/mirslava88/roland/releases/tag/v1.1.7-stream) устанавливается отдельно.

## Новое

- В контекстном меню канала с PPTX или PDF есть крупный предпросмотр на основном мониторе. Его можно развернуть на весь экран, листать экранными кнопками и быстро перейти к слайду по номеру. Предпросмотр не меняет слайд в канале и не отправляет материал в эфир.
- Стрелки клавиатуры в крупном предпросмотре заблокированы, чтобы случайное нажатие не перелистнуло эфир. Кликер с клавишами PageUp/PageDown продолжает управлять эфиром; кликер, посылающий стрелки, при открытом предпросмотре тоже блокируется.
- Левую панель материалов можно расширять перетаскиванием её правой границы. Ширина запоминается, двойной щелчок возвращает исходный размер.
- В библиотеке скрыты временные файлы Office и другие имена, начинающиеся с `~`; файлы на диске не удаляются.

## Надёжность

- Исправлено появление панели задач поверх первых слайдов PPTX на дополнительном мониторе с отличающимся масштабом Windows. Проверено на подключённом дисплее.
- При кратковременной недоступности PowerPoint PDM повторяет чтение состояния показа и сохраняет проверенное эфирное окно. Диагностика теперь фиксирует ошибки листания и источник команды выхода из эфира. Реальная проверка на конкретной проблемной презентации ещё нужна.
- Сохранены возможности и исправления [1.1.6](https://github.com/mirslava88/roland/releases/tag/v1.1.6). Анимации и встроенное видео PPTX в крупном предпросмотре не воспроизводятся; эфирный показ не менялся.

Electron 44.9.3. Установщик `PDM-Setup-1.1.7.exe` не подписан коммерческим сертификатом, поэтому Windows SmartScreen может показать предупреждение. Виртуальная камера доступна только на Windows 11.
