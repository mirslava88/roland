# PDM 1.1.7 — таймер и часы на эфирном экране

Windows x64. Исправлено расхождение между предпросмотром таймера и дополнительным экраном при разных масштабах Windows. WPF таймер теперь учитывает масштаб именно эфирного дисплея: цифры таймера и текущего времени при одинаковом выбранном проценте имеют одинаковую базовую высоту. При увеличении и переходе на формат ЧЧ:ММ:СС таймер остаётся внутри экрана. Предпросмотр в настройках Таймера и Сцене показывает допустимый размер и положение.

Сохранены отдельные часы ЧЧ:ММ для основного эфира и суфлёра, а также автоматическая ширина названия презентации в суфлёре. Electron 45.3.3. Номер приложения остаётся 1.1.7; предыдущие установщики сохранены. Виртуальная камера доступна на Windows 11. Установщик не подписан коммерческим сертификатом, поэтому SmartScreen может показать предупреждение.
