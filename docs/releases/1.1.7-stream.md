# Presentation Display Manager Stream 1.1.7

Windows x64. Stream включает RTMP/RTMPS и устанавливается отдельно от [обычной PDM 1.1.7](https://github.com/mirslava88/roland/releases/tag/v1.1.7).

## Новое

- Компактная проверка PPTX прямо в канале показывает наличие видео, аудио, анимаций и отсутствующих шрифтов; подробности с номерами слайдов открываются по нажатию.
- В «Видео» и «Музыке» добавлены сортировка плейлиста мышью, выбор следующего файла или канала, автоматическое обновление папок и запуск двойным щелчком. Видеоканал поддерживает настраиваемый автозапуск при отправке в эфир; музыкальный канал — управление из нижней панели. Очереди верхних панелей сохраняются при запуске файла из канала.
- Крупный независимый предпросмотр PPTX и PDF из контекстного меню канала: полноэкранный режим, кнопки листания и переход по номеру слайда. Эфир и выбранный слайд канала от действий в предпросмотре не меняются.
- Стрелки клавиатуры в предпросмотре заблокированы от случайного листания эфира; кликер с PageUp/PageDown продолжает работать. Если пульт посылает стрелки, они также блокируются на время предпросмотра.
- Левая панель материалов расширяется мышью, запоминает ширину и сбрасывается двойным щелчком. Временные файлы Office с именем на `~` не показываются.
- Устранено появление панели задач на эфирном мониторе с другим DPI в первые секунды показа PPTX. Кратковременный сбой доступа к PowerPoint не забывает подтверждённое окно показа; ошибки листания и источник выхода пишутся в диагностику.
- При активном эфире Windows получает запрос удерживать экран и компьютер включёнными, в том числе для неподвижной картинки и Сцены без презентации. После выхода из эфира запрос снимается; ручная блокировка остаётся доступной.

Сохранены функции и исправления [1.1.6 stream](https://github.com/mirslava88/roland/releases/tag/v1.1.6-stream). Крупный предпросмотр остаётся статическим: анимации и встроенное видео PPTX в нём не воспроизводятся. Требуется Microsoft PowerPoint для PPTX. Electron 45.2.3. Установщик `PDM-Stream-Setup-1.1.7-stream.exe` не подписан коммерческим сертификатом; виртуальная камера доступна только на Windows 11.
