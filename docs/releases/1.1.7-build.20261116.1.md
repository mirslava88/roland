# PDM 1.1.7 — обновление Electron

Windows x64. Приложение пересобрано на Electron 45.3.3. Версия PDM и функции остались 1.1.7. Ранее выпущенные установщики сохранены.

Установщик не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение. Виртуальная камера доступна на Windows 11.
