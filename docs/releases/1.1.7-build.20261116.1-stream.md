# PDM Stream 1.1.7 — обновление Electron

Windows x64. Приложение пересобрано на Electron 45.3.3. Версия PDM Stream и функции остались 1.1.7-stream. Ранее выпущенные установщики сохранены.

Установщик не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение. Виртуальная камера доступна на Windows 11.
